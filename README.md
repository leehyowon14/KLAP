# KLAP macOS

메뉴바에 상주하는 KLAS 학습 관리 앱의 개발 버전입니다. Dock 아이콘 없이 실행되며, 팝오버를 닫아도 작업은 계속됩니다.

## 실행

macOS 13 이상, Swift 5.9 이상과 Go가 필요합니다. 이 개발 환경에서는 Xcode 없이 Command Line Tools로 빌드했습니다.

```sh
bash scripts/build.sh
open dist/KLAP.app
```

빌드 시 기본적으로 `../KLAP_cli`의 `Bridge/core-ref` 커밋을 읽습니다. 다른 위치는 `KLAP_CLI_SOURCE`로 지정합니다. 원본 저장소를 수정하지 않고 `.build`에 해당 커밋을 펼칩니다. 앱에는 Go 코어와 EventKit 실행 파일이 포함되므로 실행할 때 별도 CLI 설치가 필요하지 않습니다. 현재 패키지는 빌드한 Mac의 아키텍처를 대상으로 합니다.

## 첫 실행

1. KLAS 로그인 또는 기존 CLI 계정 사용
2. 캘린더·미리 알림 권한 요청
3. 시간표, 학사일정, 미리 알림의 등록 대상 선택 또는 전용 대상 생성
4. 자동 동기화·수강 알림 설정 후 첫 동기화

권한을 거부하거나 준비되지 않았다면 ‘나중에 설정’을 사용할 수 있습니다. 동기화 대상 설정 전에는 동기화를 실행하지 않습니다. 설정에서 대상 선택을 다시 열 수 있습니다. CLI와 계정·학기·동기화 설정을 공유하며, 등록 대상을 바꾸더라도 이전 대상의 일정은 자동 삭제하지 않습니다.

## 구현

- NSStatusItem + LSUIElement로 메뉴바 상주 및 Dock 숨김
- 하단 고정 주간 시간표, 주말·야간·연속 수업과 겹침 배치
- 과목별 과제·공지·강의 조회 및 강의 페이지 열기
- 선택 강의, 과목 또는 전체 수강 가능 강의 자동 수강과 취소
- 메뉴바 원형 진행률과 순서 표시, 강의 완료·전환·전체 종료·실패 알림
- 서버 완료 응답 확인 후 완료 알림 전송
- 실행 중 30분 주기, 잠자기 복귀, 네트워크 복구 시 갱신
- 캘린더·미리 알림 동기화, 부분 실패 표시와 변경 충돌 선택
- 온보딩 권한 요청 및 대상 선택, 중복된 대상 이름 제외

## 검증

```sh
swift run --build-system native KLAPCoreChecks
bash scripts/build-core.sh
bash scripts/build.sh
codesign --verify --deep --strict dist/KLAP.app
plutil -lint dist/KLAP.app/Contents/Info.plist
```

XCTest가 포함되지 않은 개발 환경에서도 실행되도록 Swift 검증은 실행 파일 방식으로 제공합니다. 진행률, 시간표 범위·겹침, 빈 응답, 대상 이름 충돌을 검증합니다. Go 수강 큐 테스트는 빈 선택·중복·실패·미완료 응답·취소 후 다음 작업 방지를 검증합니다.

## 1.0 전 남은 검증

- 실제 KLAS 계정의 조회·수강·취소와 서버 상태 재조회
- 실제 EventKit 권한 허용·거부 및 대상별 동기화와 충돌 처리
- 시스템 알림과 메뉴바 진행률의 실사용 화면 검증
- 장시간 실행, 잠자기 복귀, 오프라인 전환 실기기 검증
- CLI 동시 실행과 공유 설정 변경 시 동작 검증
- 로그인 시 자동 실행, 배포용 Developer ID 서명·공증, universal 패키징

현재 서명은 로컬 실행용 ad hoc 서명입니다. GUI 확인 도구가 시간 초과하여 화면 조작 검증은 완료하지 못했습니다. macOS 프로세스 정보에서 실행 상태와 `UIElement` 등록은 확인했습니다.
